# Native media probe pilot contract

This is a bounded implementation/test seam for indexing presentation timestamps and decoding exact indexed frames from a locally owned clip. It is not a complete A003 implementation, production media importer, accuracy claim, camera/photo/file integration, encoder feature, or clinical/hardware validation.

`MediaProbe` retains each source `CMTime` and exposes canonical microseconds using scale 1,000,000 and `.roundHalfAwayFromZero`. Only valid numeric positive-timescale, nonnegative epoch-zero times are accepted. Semantic time equality uses `CMTimeCompare`; duplicate source timestamps and distinct source times collapsing to one canonical microsecond are rejected. Frames are sorted by presentation time while retaining source times. Frame ordinal is only the index identity, not evidence of decoded pixels. Image requests must equal an indexed source time exactly, and image-generator actual time must semantically equal that request; no nearest-frame fallback is permitted. A manifest is bound to the normalized source URL used to inspect it; this pilot does not guarantee identity against later mutation of a file at that path.

The pilot accepts only one 320x240 video track, no audio, and identity preferred transform. It bounds the index at 256 samples, reads compressed sample timing on the source axis, and fails closed on unsupported layouts, invalid timestamps, reader failures, or image decode/time mismatch. Writer readiness, writer completion, and each image-generator request have finite 10-second operation deadlines with cancellation. It does not shift timestamps, infer frame rate, support B-frame behavior as a qualified contract, or claim arbitrary-asset support. The writer fixtures use a 600-timescale source axis and an explicit tail after the last frame; fixtures begin at epoch zero. The pilot normalizer's handling of nonzero PTS is not end-to-end qualified.

XCTest creates ephemeral H.264 MOV files (six frames, no audio) with fixed broad binary frame-ID cells (three bits encode six frame identities). The independent test oracle examines decoded bitmap cells; hand-authored timestamp expectations are separate from production normalization. CFR and VFR tests compare every indexed source PTS against independent cadence ticks using semantic `CMTimeCompare`, and log actual rational source PTS and decoded pixel IDs. Fixture directories are unique temporary directories removed by `defer`; no media binary is checked in. Codec/HDR input enforcement is not qualified; H.264 all-keyframe fixtures are the only exercised format.

## Deferred native validation

Native build and tests have not been run in this Windows environment. The authoritative ARM64 workflow requires its prebuilt `JumpCoreSpike.framework` producer artifact (`JUMP_FRAMEWORK_DIR`); consult `docs/apple/PROTOTYPE.md` and the existing public workflow for the verified build recipe. The test budget remains bounded (25 minutes); do not infer test success from this contract or source inspection.

This pilot does not establish frame-accuracy metrics, rotated-track support, broader dimensions/formats, long-clip/resource behavior, Photos/Files access, production ingestion, B-frame timing qualifications, codec/HDR rejection, or physical-clock proof. Actual-time mismatch validation is covered by the pure comparison helper, not by forcing a real generator mismatch. API references: [AVAssetImageGenerator asynchronous generation](https://developer.apple.com/documentation/avfoundation/avassetimagegenerator/generatecgimagesasynchronously(fortimes:completionhandler:)), [AVAssetImageGenerator cancellation](https://developer.apple.com/documentation/avfoundation/avassetimagegenerator/cancelallcgimagegeneration()), and [AVAssetReader](https://developer.apple.com/documentation/avfoundation/avassetreader).
