# Privacy update for OpenJump 1.3

## English

When you save a multi-frame angle analysis, OpenJump keeps the selected frame images in the app's private storage and the analysis data in its local database. These images can include recognizable people or surroundings. The analysis does not copy the original video into the database. You can view or deliberately share the saved images from History. OpenJump does not automatically upload them. The recipient app or service controls its own copies.

A manual backup created in 1.3 is a ZIP archive that can include saved angle images and their analysis data. It does not contain the original videos or their links. The archive is not encrypted; the document provider you choose can access or synchronize it. Keep backups and exported images somewhere you trust. Restoring a backup replaces the current data; it does not merge. Older JSON backups do not include the new image data. Deleting local results does not delete external copies or backups.

## Español

Cuando guardas un análisis de ángulos de varios fotogramas, OpenJump conserva las imágenes seleccionadas en el almacenamiento privado de la app y los datos del análisis en la base de datos local. Esas imágenes pueden mostrar personas reconocibles o su entorno. El análisis no copia el vídeo original en la base de datos. Puedes consultar o compartir las imágenes guardadas desde el Historial. OpenJump no las sube automáticamente. La aplicación o servicio de destino controla sus propias copias.

La copia manual creada en la versión 1.3 es un archivo ZIP que puede incluir las imágenes de ángulos guardadas y sus datos de análisis. No incluye los vídeos originales ni sus enlaces. El archivo no está cifrado; el proveedor de documentos que elijas puede acceder a él o sincronizarlo. Guarda las copias y las imágenes exportadas en un lugar de confianza. Restaurar una copia reemplaza los datos actuales: no los combina. Las copias JSON antiguas no incluyen los nuevos datos de imágenes. Borrar resultados locales no elimina copias externas ni archivos de respaldo.
